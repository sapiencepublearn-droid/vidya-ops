# School History

The School History screen follows the supplied `School History(1).xlsx` structure for 2025-2026.

Sections included in the school record:
- Basic school details: Vintage, Books, Category
- Contacts: Correspondent, Principal, Key Person
- Books & Payment: LKG, UKG, Discount, SP Invoice Value (25-26), Additional Orders, Amount Received, Date, Amount Pending, Status, Remarks
- Deliverables 1: Teachers Copy, Teachers Manual 1, Teachers Manual 2, Flash Cards
- Deliverables 2: WhatsApp, Windows App, Kids App, app versions/dates/LKG/UKG/System-TV-Both, comments
- Deliverables 3: Question Paper, Progress Card
- Services: T1, T2, General Visit, ATU 2, SIM 2, T3, SIM 3 and comments
- Current Status and Comments

The Excel supplied by the user is a blank structure/template; it contains no populated school-specific values. The application therefore stores these fields for admin entry rather than inventing values.
